# 验收用例计划

本文件是计划，不是测试报告。**全部业务用例当前为 NOT_RUN，实际输出和证据均未产生。** 预期采用 [DECISIONS.md](DECISIONS.md) 中暂拟解释；S1 采纳或调整后同步修订预期并留痕，不按运行结果倒改预期。

当前只包含第一阶段 26 组用例。每组内的边界子用例必须分别留结果，不能跑一个示例便宣称整组通过；第二阶段不列入当前测试计划。

通用前置：已验证环境、专用测试数据库、合成账号 A/B/C、独立的问卷与发布版本；禁止使用 Lab 现有数据。接口路径、HTTP 状态码与命令在 S2 契约确定后补齐；当前只定义行为预期。随机数据固定并记录种子。涉及持久化与并发必须用真实 MongoDB。

分层执行：S3 仅验收已实现的账号/管理/填写入口子用例；S4 的校验与路径测试直接调用同一个服务端校验器/求值器；S5 补齐提交、统计、明细 API 子用例并重测集成；S6 完整回归第一阶段 26 组。未实现接口返回 404 不算权限或校验成功。

每次运行记录：用例/子用例 ID、需求 ID、阶段、时间时区、执行者、环境和代码版本、前置条件、具体步骤与命令、输入、预期、实际、PASS/FAIL/NOT_RUN/BLOCKED、退出码、证据路径、清理范围。模板见 [EXPERIMENT_LOG.md](EXPERIMENT_LOG.md)。

## 账号与管理

### TC-A01 注册与登录

关联 R02。步骤：注册 A，检查数据库用户字段，再正常登录；重复注册用户名、错误密码各执行一次。输入：合成用户名/密码。预期：成功用户有注册时间且仅保存密码哈希；正确登录成功，重名和错误密码被拒绝；日志不含密码。

### TC-A02 填写前认证

关联 R02/R03/R10。步骤：未登录访问管理及填写接口，之后登录访问已发布分享链接。预期：未认证者不能管理、填写或提交；已登录者可进入符合生命周期条件的问卷。匿名开关不绕过登录。

分批：管理/填写入口认证在 S3 验收，提交接口认证在 S5 补齐；两部分均完成才算整组通过。

### TC-A03 服务端拥有者隔离

关联 R02/R11。步骤：A 创建问卷，B 获取其 ID 后直接请求详情、修改、发布、关闭、统计、答案原文；检查 B 列表。预期：B 列表不含 A 问卷，各管理调用拒绝且无数据改变；分享填写接口按填写权限单独处理。若后续有删除/导出接口也加入此用例。

分批：S3 验证已实现的详情/修改/发布/关闭/列表，S5 验证统计/答案明细；未实现接口必须标 NOT_RUN，不纳入已通过证据。

### TC-Q01 创建问卷

关联 R03。步骤：A 创建含标题、说明、匿名和重复开关的草稿，查看本人列表，再以 B 查看。预期：字段和拥有者正确持久化，A 可见、B 不可见；空标题或非法时间配置拒绝。

### TC-Q02 添加题目与发布配置

关联 R04/R05/R06/R07。步骤：向草稿分别加入单选、多选、文本、数字题，保存并重读；发布后尝试修改题目和影响判重的策略。预期：稳定题目/选项 ID、顺序与约束不丢失；发布快照不可变；非法字段/配置拒绝。S3 可先验证配置合法性，运行期规则由 S4 验证。

### TC-Q03 发布与生命周期预检

关联 R03。步骤：草稿分享链接读取、发布后读取、设置截止时间、关闭后读取；另建到期问卷检查读取提示。预期：仅当前有效发布版本进入填写，草稿/关闭/到期有明确拒绝或只读提示，分享码稳定；不合法跳转配置不能发布。**此用例不验证最终提交，提交边界在 TC-R05 执行，避免 S3 依赖 S5。**

## 题目校验

### TC-V01 单选

关联 R04。步骤：必答题分别提交无值、合法选项、未知选项及多个值；可选题空答。预期：仅合法单值及允许的空答通过，其余返回具体题目错误。

### TC-V02 多选数量

关联 R05。步骤：四个选项，分别设置 min=2、max=3、exact=2；用 1/2/3/4 个选择逐项验证，再提交重复 ID 和未知 ID。预期：各边界符合配置；重复或非法选项拒绝，不靠去重后计数悄悄接受。

### TC-V03 文本长度

关联 R06。步骤：min=2/max=4，提交长度 1/2/4/5 的中文/英文/含表情文本及全空白；可选题空答。预期：按采纳的码点与空白口径处理，边界包含；保留合法原文。记录表情组合字符的计数口径。

### TC-V04 数字边界

关联 R07。步骤：整数年龄题 0–120，提交 -1、0、120、121、1.5、1.0；再对允许小数的题提交小数；测试非数字、布尔值、NaN/Infinity。预期：有效范围和整数口径一致；非法非有限值/类型拒绝，不发生静默截断。

### TC-V05 配置自身合法性

关联 R05/R07/R08。步骤：建立 min>max、负计数、exact 超选项数、冲突 exact/min/max、重复题目/选项 ID、空多选条件、错误数字操作符等配置。预期：保存或发布时明确拒绝；不等用户填写后才发现无法满足。

## 跳转逻辑

### TC-J01 单选分支

关联 R08。步骤：配置 Q1 选 A→Q5、选 B→Q3；分别填写，再把配置目标更改后新建草稿发布。预期：进入配置指定题目，规则变化不需要修改程序，已发布旧版本不被覆盖。

### TC-J02 多选分支

关联 R08。步骤：分别设置 ANY 与 ALL 条件，提交空、部分命中、全命中和多规则同时命中。预期：按已采纳条件和显式优先级进入唯一确定目标；空集合不命中。

### TC-J03 数字分支

关联 R07/R08。步骤：针对 eq/lt/lte/gt/gte 配置阈值，输入低于、等于、高于阈值。预期：边界及目标正确，非法数值先被校验拒绝。

### TC-J04 默认路径与发布图校验

关联 R08。步骤：无条件命中时逐题到结束；再配置同优先级、自环、回跳和不存在目标。预期：无命中顺序前进；无效规则拒绝发布，不出现死循环。普通末题提交无需“跳到不存在的下一题”。

### TC-J05 路径重算与必答

关联 R04/R08/R09。步骤：跳过一个必答题完成可达路径；回改早期答案改走另一分支；直接向服务端提交旧路径答案、伪造路径和漏答的新路径必答题。预期：跳过题不误报；页面清理旧答案；服务端重算并拒绝路径外/缺失答案。

子用例 TC-J05a（S4）：直接调用服务端路径校验器并检查页面重算；TC-J05b（S5）：通过实际提交 API 发送同类载荷，验证拒绝且无成功答卷写入。两部分均通过才算整组通过。

## 提交与并发

### TC-R01 成功提交与持久化

关联 R09。步骤：完整走一条合法路径提交，用真实 MongoDB 重读，再重启应用读取统计。预期：保存一份带问卷/版本/路径/答案的独立答卷；重启后仍可读，其他人的答卷不被覆盖。

### TC-R02 非法提交不落成功答卷

关联 R08/R09。步骤：提交缺必答、非法选项、路径外题、陌生题 ID、旧版本及客户端篡改配置。预期：返回可定位错误，成功答卷数不增加；客户端不能决定拥有者或篡改服务端约束。

### TC-R03 允许重复与重试幂等

关联 R10。步骤：禁重复下同账号两次提交；允许重复下用两个新请求 ID 主动提交；相同请求 ID 相同内容重试，再改内容重试。预期：禁重复只接受一份，允许重复保存两份；同 ID 同内容只一份，同 ID 不同内容拒绝。核对数据库条数和 ID。

### TC-R04 匿名与身份隔离

关联 R10/R11。步骤：在匿名问卷提交，创建者查看整卷/单题统计、答案明细及实际存在的导出入口；对比非匿名问卷；匿名下重复提交再测试。预期：匿名结果无账号、私有判重标识或可逆身份字段；判重仍正确。记录此匿名范围，不宣称不可追溯。

### TC-R05 并发及截止关闭竞争

关联 R03/R09/R10。步骤：预设 n=10 个合成用户同时合法提交；同账号在禁重复模式同时发 10 个不同 ID 请求；同 ID 并发重试；允许重复用不同 ID 并发；再运行“先关闭后提交”“先受理后关闭”“恰好截止/截止前/截止后”及已打开页面晚提交。预期：按 D07/S2 定义的先后边界接受或拒绝；合法独立提交不丢失，判重只一份，允许重复不误拦截，关闭/截止后不受理。记录请求/成功/拒绝数、错误类型、数据库 ID/数量对账及起跑同步方式；负载只是正确性夹具，不作为性能达标指标。

## 统计

### TC-S01 可手算统计夹具

关联 R11。步骤：创建固定发布版本并开启允许重复填写，录入下方三份成功答卷，查询整卷和各题统计。预期：与下方计算完全一致；数字平均不把跳过补零。输入为人工构造的测试夹具，**尚未执行**。

```text
u1 的提交 r1：单选 A；多选 [X,Y]；文本「甲」；数字 10
u2 的提交 r2：单选 B；多选 [Y]；文本「乙」；数字 20
u1 的提交 r3：单选 A；多选 [X]；文本「丙」；数字题被路径跳过

预期计算值：提交 3 份，去重填写 2 人。
单选：A 2次/1人，B 1次/1人，有效回答3份/2人。
多选：X 2次，Y 2次；文本保留「甲」「乙」「丙」。
数字：有效回答2份，均值(10+20)/2=15。
```

S2 需把该数据变成合法可达路径夹具，例如让 r3 对应的早期回答跳过数字题，而 r1/r2 到达。不得手工插入违反服务端规则的数据来冒充端到端成功。

### TC-S02 空答、零数据与版本

关联 R11。步骤：查询零答卷问卷、含可选空答/被跳过题的问卷，再查询不同发布版本的同名题。预期：零计数正确，数字无有效回答返回 null/暂无而非 0 或异常；空答不进均值，版本不混合；整卷和单题口径一致。

### TC-S03 统计权限与内容

关联 R02/R10/R11。步骤：创建者查看选项计数、总有效回答数及全部文本/数字原文，B 越权请求；匿名下检查响应字段。预期：创建者得到完整本卷结果，他人不可读取；匿名身份不可泄露，界面区分提交次数与人数。
